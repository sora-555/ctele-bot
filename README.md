# CosplayTele Telegram Bot

Standalone aiogram v3 + FastAPI + SQLAlchemy scaffold for the CosplayTele SDK. Copy your own **ctele/** package into this project root; it is intentionally not included in bot.zip and is never generated by this project.

## Run
1. Copy ctele/ separately from the supplied SDK.
2. Copy .env.example to .env and set BOT_TOKEN.
3. Install Python 3.11+ dependencies: pip install -r requirements.txt
4. Run: python start.py

Polling is the default and FastAPI health endpoints remain available on API_PORT. Set RUN_MODE=webhook and WEBHOOK_BASE_URL for webhook hosting. SQLite is created automatically.

## Navigation
Search uses one editable result card with source-page-aware wording, compact user-scoped session IDs, number shortcuts and a reply-based jump. Opening a result directly enters the single-image viewer; previous/next, first/last, ±5, information/favorites hooks, and exact back navigation are designed around edit_message_media. Album delivery can be added without changing session references.

## Archive manifest
The archive contains only project files: start.py, requirements.txt, .env.example, .gitignore, README.md, plan.md, and bot/. It excludes attached_assets, ctele/, .git, virtual environments, caches, Database.db and logs.

Known limitation: optional album mode and some account/admin screens are scaffold extension points; SDK search pages do not expose a reliable global total, so the UI never invents one.
